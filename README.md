# KVPY / JEE Advanced Physics

*A Skills-Based Textbook in Five Units* by Mitali Aayat Mahnoor (First Edition, 2026)

A physics textbook for students preparing for KVPY-style and JEE Advanced problems, where a familiar principle shows up in an unfamiliar disguise.

- **5 units, 19 topics, 36 chapters**, each built on one learning objective
- Every chapter trains one of five science practices: mathematical modeling, multi-concept synthesis, constraint and frame analysis, approximations and limiting cases, graphical interpretation
- Worked examples, common pitfalls, chapter reviews, conceptual questions, problems and challenge problems, with a full answer key
- Glossary, formula sheet and maths toolkit
